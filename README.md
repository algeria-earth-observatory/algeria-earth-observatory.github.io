# Algeria Earth Observatory (AEO)

**Open Earth Data for Algeria** — https://algeria-earth-observatory.github.io/

Algeria Earth Observatory is an open scientific initiative dedicated to making Earth observation and environmental information about Algeria accessible, discoverable, reusable, and scientifically documented. This repository contains the public website: a documented data catalog, an interactive map explorer, methods documentation and contribution workflows.

AEO is an independent initiative in its initial development phase. It is not a government service and is not affiliated with or endorsed by any institution.

## What is here

| Path | Content |
|---|---|
| `src/content/datasets/` | One JSON metadata record per dataset (the catalog). Validated at build time. |
| `src/content/docs/` | Methods and documentation guides (Markdown). |
| `src/data/map-layers.ts` | Map explorer layer registry; every overlay links to a catalog record. |
| `src/data/gibs-layers.json` | NASA GIBS layer metadata, generated by `scripts/fetch_gibs_layers.py`. |
| `public/data/aeo/` | Small, openly licensed AEO-distributed files (versioned folders, SHA-256 in records). |
| `scripts/` | Build checks (`validate-catalog`, `postbuild-check`, `check-links`, `checksums`). |
| `scripts/processing/` | Reproducible processing code for AEO-derived data (boundaries, hero image, planned-product stubs). |
| `scripts/tutorials/` | Tested tutorial scripts (Python, R). |
| `docs/` | Architecture, deployment and maintenance guide, roadmap, source audit, review checklist. |
| `org/` | Content for the GitHub organisation profile (`.github` repository). |
| `research/` | Verification notes and audit tables produced while building the catalog. |

## Quick start

Requires Node.js 20.3 or later.

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # validates the catalog, builds to dist/, checks internal links
npm run preview    # serves dist/
npm run check      # TypeScript / Astro diagnostics
npm run check:links  # tests every external URL in the catalog (network)
```

## Adding or editing a dataset

1. Copy an existing record in `src/content/datasets/` and rename it `<id>.json` (kebab-case; the id must equal the file name).
2. Fill every field from official sources only. Unknown values are `null` and listed in `verification.unverified_fields`.
3. `npm run build`. The schema (`src/content.config.ts`) rejects incomplete or inconsistent records with a message naming the field.

Full rules: [`docs/METADATA_SCHEMA.md`](docs/METADATA_SCHEMA.md) and the [review checklist](docs/DATASET_REVIEW_CHECKLIST.md).

## Technology

Astro 5 (static output) · TypeScript · Tailwind CSS 4 · MapLibre GL JS 5 · JSON metadata with build-time Zod validation · GitHub Actions → GitHub Pages. No server, database, API key or paid service is required.
